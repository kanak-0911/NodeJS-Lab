# Lab 06 – Working With The File System (fs) Module

**Lab Number:** 06
**Date:** 25-09-2026

## Files and Their Purpose

* **read-async.js** – Reads the sample file asynchronously using the `fs` module.
* **read-sync.js** – Reads the sample file synchronously using the `fs` module.
* **write-file.js** – Creates a file and writes content into it.
* **append-file.js** – Adds new content to the end of an existing file.
* **delete-file.js** – Deletes a file using the `fs.unlink()` method.
* **async-await-version.js** – Copies file content using async/await with `fs.promises`.
* **add-note.js** – Adds a note to the notes file using a command-line argument.
* **read-notes.js** – Reads and displays all saved notes from the notes file.
